# Pancadaria no Planalto

Jogo de luta arcade 2D em tom de paródia política, feito com HTML, CSS e JavaScript puro.

## Executar localmente

Abra `dist/index.html` no navegador ou sirva a pasta `dist` com um servidor HTTP local.

## Publicar na Vercel

O projeto é estático e não precisa de etapa de build. A configuração em `vercel.json` publica a pasta `dist`.
